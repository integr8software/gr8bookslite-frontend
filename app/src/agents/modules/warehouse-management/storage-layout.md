# Storage Layout

Storage Layout shows the structure of one selected warehouse visually.

## Scope

- UI shell only.
- Should display hierarchy, rack, grid, or map-style views after storage locations are backed by data.

## Key Rules

- Always show the selected warehouse prominently.
- Do not allow editing multiple warehouses in one layout.
- `All Warehouses` is allowed only for summary or comparison views.

## Future Views

- Hierarchy or tree view
- Rack or grid view
- Warehouse map
- Occupancy indicators
- Blocked or unavailable locations
